### PY_DOOM
pygame 라이브러리를 통해 제작한 FPS 게임입니다.

##

### 조작법
| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 카메라 회전 |
| SPACE | 점프 |
| LSHIFT | 슬라이딩 |
| 좌클릭 | 사격 |
| R | 재장전 |
| 1 | 포션 사용 |
| ESC | 일시정지 |
| F11 | 전체화면 토글 |

##

### 주요 기능
- 레이캐스팅을 활용하여 2D게임을 시각적으로 3D처럼 보이게 렌더링합니다.
- 플레이어의 z축(수직) 방향 물리를 직접 구현했습니다.
- 슬라이딩 시 관성을 적용하여 속도가 증감됩니다.
- 적 AI (시야 감지, 추적, 공격, 플레이어와 적 사이 벽 여부 확인 등)를 직접 구현했습니다.
- 상태 관리 시스템으로 메인메뉴 / 인게임 / 일시정지 / 게임오버 화면을 효율적으로 렌더링합니다.
- 총성, 피격, 재장전 등 특정 행동에 사운드가 적용되어 있습니다.
